## Ficha D2-C. Comparabilidad del diagnóstico entre períodos

> **En palabras sencillas:** ¿Hay evidencia comparable para hablar de cambios de aprendizaje?
>
> Autoría: Cynthia Mercedes Gorozabel Villavicencio. Evidencia del caso documental; datos individuales originales reservados. Los datos sintéticos se consultan por separado.


**Dimensión.** Intersyllabus

**Pregunta del indicador.** ¿La continuidad o el cambio del sílabo permite comparar logro de RA entre estudiantes de distintos períodos?

**Unidad de análisis.** Relación entre versiones curriculares, cobertura de evaluación y evidencia estudiantil disponible.

**Cómo se hizo.** Se examinó si había actas e instrumentos por período, vínculos actividad-RA y criterios de evaluación equivalentes. Se distinguió comparar planificación de comparar desempeño.

**Dónde se prueba.** S1-S3 pp.1-4; A1 p.1, período abril-agosto 2025. Inventario de fuentes del JSON e informe, sección 3.

**Evidencia observada.** Se dispone de tres versiones de sílabo, pero solo un acta, correspondiente al período S1. No hay notas desagregadas por RA, tareas calificadas ni instrumentos equivalentes entre períodos.

**Razonamiento.** La igualdad de un RA o una columna de nota no garantiza que las tareas y criterios sean equivalentes. Si las consignas cambian, el mismo rótulo puede referirse a exigencias distintas. La ausencia de datos de S2-S3 impide el contraste de resultados entre períodos.

**Conclusión permitida.** Puede compararse la planificación documental; no puede establecerse una evolución del desempeño estudiantil por RA con estas fuentes.

**Qué no acredita.** No permite atribuir un cambio de aprendizaje al sílabo, ni afirmar mejora o deterioro de una cohorte.

**Estado metodológico.** SUP / EVIDENCIA_INSUFICIENTE para comparación de desempeño

**Revisión o dato pendiente.** Reunir datos de los otros períodos y justificar equivalencia de actividades, rúbricas, escalas y cobertura antes de comparar.

# Gobernanza de la metodología

## Reglas vigentes

- No inventar datos del caso real, completar nulos o repartir notas entre RA sin evidencia.
- Diferenciar hechos, decisiones humanas e interpretaciones propuestas.
- Mantener aisladas conceptualización, caracterización de datos, definición de indicadores y cálculos de integridad.
- Conservar el indicador macro-micro como cualitativo, sin porcentajes ni escala 1–5 no validada.
- El alcance vigente interpreta registros; no produce promedios ni nuevas ponderaciones.
- Los datos sintéticos se identifican en cada archivo y no se utilizan como evidencia empírica.
- No sustituir el objetivo global por el RA de una sola unidad.

## Estados

| Código | Significado |
|---|---|
| SRC | Información de la fuente primaria |
| DEC | Decisión o aclaración humana explícita |
| SUP | Deducción directa comprobable |
| INF | Interpretación indirecta que debe explicitar sus supuestos |
| PROP | Propuesta pendiente de validación |
| UNKNOWN | Información no disponible |
| CONTR | Contradicción por registrar y resolver en el vínculo afectado |

REVIEW_REQUIRED indica revisión pendiente; NOT_CALCULABLE señala falta de identificabilidad de la variable pedida. No son dictámenes de fracaso. Una contradicción detiene la conclusión afectada, sin ocultar comprobaciones independientes.

## Estado del proyecto

El antecedente de trabajo describía una arquitectura conceptual y una puerta READY_WITH_CONDITIONS, con rúbrica pendiente. Este repositorio no hereda una certificación científica o institucional de ese texto. Contiene documentos, scripts de demostración y fichas revisables, no una plataforma de producción ni un motor semántico validado.
